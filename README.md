# MEDICONNECT — working website demo

A responsive, interactive healthcare appointment-booking **student project demo** built with HTML, CSS and JavaScript. It does not require a build tool or AI credits.

## Run it

1. Download and unzip `mediconnect_website.zip`.
2. Open the `mediconnect_website` folder in VS Code.
3. Recommended: install the VS Code extension **Live Server**.
4. Right-click `index.html` → **Open with Live Server**.
5. The website should open in your browser.

You can also open `index.html` directly in a browser, but Live Server is recommended.

## Included interactions

- Eight connected sections/pages: Home, Find Doctor, Doctor Profile, Book Appointment, Appointments, Health Records, Health Articles, and Profile.
- Doctor search, specialty filters, sorting, and favorite toggles.
- Selectable appointment dates, time slots, and consultation type.
- Demo booking confirmation and cancellation.
- Appointments and favorite doctors saved in browser local storage.
- Article search/category filtering and sample record details.
- Responsive desktop/tablet/mobile layout.

## Publish for your teacher

### GitHub Pages (free static hosting)

1. Create or sign in to a GitHub account.
2. Create a new **public** repository, e.g. `mediconnect-demo`.
3. Upload `index.html`, `styles.css`, `app.js`, and `README.md` to the repository root (or upload the unzipped project contents).
4. In the repository, open **Settings → Pages**.
5. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
6. Wait for the deployment to finish; GitHub will show a public website URL in Pages settings.
7. Open that URL in a private/incognito browser window and test every page.

Hosting interfaces may change; follow GitHub's current Pages prompts if labels differ.

## Important demo limitations

- Doctor profiles, reviews, articles and records are sample content.
- Booking is stored only in the visitor's browser; it does not contact a hospital.
- No real payments, accounts, authentication, or secure medical-record backend are implemented.
- Do not enter real patient or sensitive medical data.
- Doctor/article images and Google Fonts use external internet resources. The site remains usable without them, but imagery/fonts may fall back.
